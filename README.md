# Gif Maker

This project converts pictures to gifs, enables to edit the frames and how it will be played.
You can start new project or load an old one to resume from where you left off.

## Options

* ```0``` - Exit
* ```1``` - Add new frame
* ```2``` - Remove frame
* ```3``` - Change index
* ```4``` - Change frame duration
* ```5``` - Change duration of all frames
* ```6``` - List frames
* ```7``` - Play the movie
* ```8``` - Save the project
* ```9``` - Play the movie in reverse
* ```10``` - Play the movie in black and white
